# HYIP Monitor Pro

Production-Ready MERN Stack High-Yield Investment Program (HYIP) Monitoring & Verification Platform.

## 🚀 Features

- **Class Component Architecture**: 100% written using React Class Components (`class ... extends Component`), `.js` file extensions, and clean state management (Zero hooks).
- **HYIPExplorer Inspired Visual Fidelity**:
  - Live status badges (`PAYING`, `WAITING`, `NOT PAYING`, `SCAM`, `NEW`, `FEATURED`)
  - Categorized groups: *Class "Premium" (TOP Choices)*, *Class "A" (Top Performer)*, *Class "B" (Trial)*, *Not Paying Blacklist*
  - Detailed investment plan breakdown, ROI yield, deposit limits, payment processors (BTC, USDT, ETH, PM, Payeer, LTC)
  - Live daily payout logs with TxHash/Batch ID verification
  - Domain WHOIS & hosting infrastructure inspection
- **User Reviews & Evidence Uploads**: Visitors can post verified payout proofs, screenshots, and ratings.
- **Scam Protection & Reports**: Blacklist reporting system for delayed or selective payouts.
- **Nested Discussions**: Interactive community comments with nested replies.
- **Admin Panel**: Full CRUD project manager, review approval queue, scam investigation, banner advertising manager, and site settings.

## 🛠 Tech Stack

- **Frontend**: React (Class Components ONLY), Bootstrap 5, Bootstrap Icons, Tailwind CSS
- **Backend**: Node.js, Express.js REST API
- **Database**: MongoDB / Mongoose schema support with auto-seeding sample database fallback
- **File Uploads**: Express static `/uploads` service

## 💻 Quick Start

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Start production server
npm start
```
